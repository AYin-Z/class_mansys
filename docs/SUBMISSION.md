# 区队管理系统 — 参赛文档

## 项目简介

**区队管理系统** 是一个面向公安大学区队的综合管理平台，解决传统区队管理中通知散落、请假纸质化、班费不透明等痛点。系统覆盖通知发布与追踪、请假审批、班费管理、投票表决、心理干预、擂台挑战、积分考核等功能模块，为区队干部提供一站式工作台，为全体同学提供便捷的日常服务入口。

- **产品形态**：Web 应用 + Android APK（Capacitor 封装）
- **技术栈**：Vue 3 + TypeScript + Pinia + Vite（前端）、Express + MySQL（后端）
- **部署方式**：Cloudflare Tunnel → 阿里云 ECS，域名 cls.ayinserver.xin
- **项目地址**：https://github.com/AYin-Z/class_mansys

## 功能说明

### 🔐 用户模块
- 学号密码登录、手机验证码登录、邮箱验证码登录
- 角色权限体系（9 级角色：学员/区队长/团支书/各副区/辅导员/管理员）
- 个人信息卡片

### 📢 通知管理
- 通知发布（支持置顶、定时发布）
- 已读/未读追踪，待办完成确认
- 分类筛选和历史检索

### 🏥 请假管理
- 在线请假申请（事假/病假/公假）
- 逐级审批流程（区队长/辅导员）
- 请假状态实时跟踪，销假操作

### 💰 班费管理
- 班费收缴、支出记录、预算管理
- 使用投票审批、监督公示
- 收支报表与可视化

### 🗳️ 互动模块
- **投票活动**：创建/参与/结果公示
- **建议箱**：匿名提交→管理员处理→进度跟踪
- **擂台挑战**：学习/体能/纪律多维度挑战赛
- **抽奖活动**：积分兑换抽奖
- **积分中心**：各项活动积分累计与排名

### 📸 其他
- 区队相册（照片上传/审核/展示）
- 公告资源（文件上传/下载）
- 作业管理（发布/提交/评分）
- 心理干预申请（匿名/私密）

## 设计思路

### 架构设计
```
┌─────────────┐     ┌──────────────┐     ┌──────────┐
│  Vue 3 SPA  │────▶│ Cloudflare   │────▶│ Express  │
│  (H5/APK)   │     │ Tunnel       │     │ API 服务  │
└─────────────┘     └──────────────┘     └────┬─────┘
                                              │
                                        ┌─────▼─────┐
                                        │  MySQL DB  │
                                        └───────────┘
```

### 前端设计
- 使用 Vue 3 Composition API + `<script setup>` 全 TypeScript 开发
- 状态管理采用 Pinia（user store + module stores）
- 路由使用 vue-router（hash 模式，H5+Capacitor 兼容）
- rpx 响应式单位适配各种屏幕尺寸（1rpx = 100vw/750）
- 组件化开发，50+ 自定义组件

### 后端设计
- RESTful API 设计，Token 认证（JWT）
- 中间件链：Helmet 安全 → CORS → 速率限制 → 操作日志
- 控制器-路由分离，16 个业务路由模块
- MySQL 数据库，事务保证数据一致性

### APK 适配
- 使用 Capacitor 8 将 Web 应用封装为 Android APK
- Splash Screen 启动屏避免白屏
- Status Bar 深色适配
- Android 物理返回键处理（子页面后退，Tab 页双击退出）
- Capacitor Filesystem 提供原生文件访问能力

## 使用指南

### 访问方式
1. **浏览器访问**：打开 https://cls.ayinserver.xin
2. **Android APK**：下载安装 APK 文件

### 登录
- 首次使用需登录（学号 + 密码）
- 如未设置密码，联系管理员设置

### 主要操作
1. **查看通知**：首页→通知列表→点击查看详情
2. **请假申请**：底部 Tab「请假」→申请请假→填写信息→提交
3. **班费查询**：底部 Tab「我的」→班费记录→查看收支明细
4. **投票**：互动模块→投票活动→选择投票→提交
5. **反馈**：我的→意见反馈→填写内容→提交
